# Sample image set

The local JPG files in this directory contain several US-labelled validation products. The files are intentionally ignored by Git; this document preserves source and licensing information without redistributing the photographs.

Primary reproducible set:

- Product: Nature Valley Oats 'N Honey Granola Bars
- Barcode: `0016000264694`
- Source record: https://world.openfoodfacts.org/product/0016000264694
- Image source: Open Food Facts contributors
- License: CC BY-SA 3.0 (attribution and share-alike)

Files:

- `nature_valley_front.jpg` — raw source image 65
- `nature_valley_nutrition.jpg` — raw source image 66
- `nature_valley_ingredients.jpg` — raw source image 12

These three files pass FoodProof Fit's deterministic resolution, glare, darkness, and blur checks. Open Food Facts records are community-contributed, so the package images remain the primary evidence and should not be treated as a current manufacturer guarantee.

Additional real-photo evidence includes Campbell's Cream of Mushroom, a CLIF Bar variety pack, Doritos Nacho Cheese, and Premium Original Saltine Crackers. The Premium set came from [Open Food Facts product 0044000044831](https://world.openfoodfacts.org/product/0044000044831), with contributor images used under CC BY-SA 3.0. Its three local filenames begin with `premium_crackers_`.
